### Model structure (verify against `named_modules()`; do not trust blindly)

64 decoder layers. Layer `i` is a full-attention layer if `(i + 1) % 4 == 0`
(16 layers). The other 48 are GatedDeltaNet ("GDN", linear attention)
layers. Shapes are `input_dim → output_dim`.

| Module (under `language_model.model.layers.<i>.`) | Layers | in → out |
| --- | --- | --- |
| `linear_attn.in_proj_qkv` | GDN | 5120 → 10240 |
| `linear_attn.in_proj_z` | GDN | 5120 → 6144 |
| `linear_attn.in_proj_b` | GDN | 5120 → 48 |
| `linear_attn.in_proj_a` | GDN | 5120 → 48 |
| `linear_attn.out_proj` | GDN | 6144 → 5120 |
| `self_attn.q_proj` | attention | 5120 → 12288 |
| `self_attn.k_proj` | attention | 5120 → 1024 |
| `self_attn.v_proj` | attention | 5120 → 1024 |
| `self_attn.o_proj` | attention | 6144 → 5120 |
| `mlp.gate_proj`, `mlp.up_proj` | all | 5120 → 17408 |
| `mlp.down_proj` | all | 17408 → 5120 |
| `language_model.model.embed_tokens` | — | 248320 × 5120 |
| `language_model.lm_head` | — | 5120 → 248320 |

There are 498 quantized modules in total. Every input dimension is divisible
by 1024. `conv1d`, norms, `A_log`, and `dt_bias` stay unquantized.

Effective bits per weight with group size 128 and 16-bit scales + biases:
2-bit = 2.25, 3-bit = 3.25, 4-bit = 4.25.

### A3. Layer-by-layer forward (`stage10/layerwise.py`) — two checks required

This module runs the 64 decoder layers one at a time over many sequences
without ever holding the full BF16 model.

1. Embed the tokens.
2. For each layer, build a fresh `DecoderLayer(args, layer_idx=i)` from the
   installed mlx-lm `qwen3_5` module, load only that layer's sanitized
   weights, and run all sequences through it. Use `cache=None`, and create
   the masks exactly as `Qwen3_5TextModel.__call__` does (`fa_mask` for

   arrays and free the layer.
3. Apply the final norm, then `lm_head` in chunks of 256 positions with
   `log_softmax` in float32.

Never `mx.eval` a full 27B parameter tree.

The same module is reused by GPTQ and AWQ (Phase B). Expose hooks that
capture the inputs of each linear inside a layer.

**Check A3-loop** (on real weights; the production g128 fits in memory):

**Check A3-sanitize**:

### A5. Quantized formats (`stage10/qformat.py`) — tests required

- `pack(q, bits)`: integer codes `q` (uint8, shape [out, in], values
  0..2^bits−1) → the uint32 weight array MLX expects for `bits` ∈ {2, 3, 4}.
  For 3 bits MLX packs 8 values into 3 bytes. Write the packer, then
  **prove it by test**: for random `q`, scales, and biases,
  `mx.dequantize(pack(q, b), scales, biases, group_size=128, bits=b)` must
  equal `q * scales + biases` exactly (per group), for b = 2, 3, 4. If the
  test fails, change the packer until it passes. Do not continue before it
  passes.
- `rtn(w, bits)`: plain `mx.quantize(w, group_size=128, bits=bits)`.
- `hadamard_rotate(x, block, signs, inverse=False)`: copy the function from
  mlx-lm `prism_hadamard_qwen35.py`, but make the compute dtype a parameter
  (default float32).
- `make_signs(seed, module_path, n)`: ±1 float32 vector of length `n` from
  `np.random.default_rng([seed, zlib.crc32(module_path.encode())])`, drawn
  as `rng.integers(0, 2, n) * 2 - 1`.
- Folding rule: a linear layer `y = x @ W.T` with weight `W` [out, in] is
  stored as `W_rot = hadamard_rotate(W, block, signs)` (rotate along the
  input axis, i.e. the last axis). At runtime the input is rotated the same
  way. The embedding table is rotated the same way along its last axis and
  inverse-rotated after dequantizing rows (as in the prism code). Do the
  rotation in float32, then quantize.
- Test: for a random 256×2048 `W` and `x`,
  `x @ W.T ≈ hadamard_rotate(x) @ hadamard_rotate(W).T` (float32, max rel
  error < 1e-5), and embedding rotate → inverse round-trips.

## 5. Recipe details

### RTN (`rtn3`, and every `*-rtn` recipe)

`mx.quantize` per module with that module's bits. For rotated recipes,
rotate first (A5 folding rule), then quantize.

### GPTQ (`gptq3`, `*-gptq`)

Sequential, one layer at a time, on the 96 calibration sequences:

1. Start from the embedded calibration tokens. Use the BF16 embedding,
   rotated if the recipe is rotated, for the forward pass. The stored
   embedding itself is RTN.
2. For layer `i`, load its BF16 weights. Run all calibration sequences
   through the BF16 layer, capturing the input of every linear, and
   accumulate `H = Σ Xᵀ X` in float32 in chunks of 8 sequences. Linears
   that share an input share one `H`:
   - `in_proj_qkv`, `in_proj_z`, `in_proj_b`, `in_proj_a`;
   - `q_proj`, `k_proj`, `v_proj`;
   - `gate_proj`, `up_proj`.
   For rotated recipes, rotate the captured inputs with that module's
   rotation before accumulating.
3. Quantize every linear of the layer with GPTQ. Copy the algorithm from
   mlx-lm `mlx_lm/quant/gptq.py` **at or after commit 9974d3f**, but use
   your A5 `pack()` so that 3 bits work. Fixed settings:
   - damping `0.01 × mean(diag(H))`;
   - no activation ordering;
   - group size 128 with the lazy per-group update;
   - Cholesky in float32 on `mx.cpu`.
   If Cholesky fails, multiply the damping by 10 and retry, at most 3
   times, logging each retry. If it still fails, use RTN for that module
   and log it.
4. Run the calibration sequences through the **quantized** layer to get the
   inputs of layer `i+1`.
5. `embed_tokens` and `lm_head` use RTN with the recipe's bits.
6. Record in `build.params`: the per-module mean squared output error
   before and after GPTQ on the first 8 calibration sequences, as an array
   of numbers. Do not interpret it.

### AWQ (`awq3`, partial)

Scale search only for linear groups whose input comes straight from an
RMSNorm, plus `down_proj`. `o_proj` and `out_proj` stay plain RTN. Process
layers sequentially, as in GPTQ steps 1–4. Use the first 16 calibration
sequences for the search. For each group:

- `s = mean(|X|, over tokens) ** α`, normalized by
  `s / sqrt(max(s) * min(s))`.
- Try α in {0.0, 0.1, …, 1.0}. For each α, quantize `W · diag(s)` with RTN
  3-bit, compute the group's output MSE against the BF16 outputs with input
  `X / s`, and keep the best α. α = 0 is plain RTN.
- Fold the scales:
  - for the groups after `input_layernorm` and `post_attention_layernorm`,
    divide that norm's weight by `s` and multiply each linear's columns by
    `s`;
  - for `down_proj`, divide `up_proj`'s output rows by `s` and multiply
    `down_proj`'s columns by `s`.
- Record the chosen α per group in `build.params`.
