## 1. Diagnosis

The current implementation violates several critical invariants due to a lack of atomicity between state changes and event persistence, and a failure to enforce idempotency and lease validation.

1.  **Idempotency Failure (Invariant 1):** `POST /api/jobs` does not check for existing jobs with the same `idempotency_key` and `tenant_id`. Concurrent requests create duplicate jobs.
