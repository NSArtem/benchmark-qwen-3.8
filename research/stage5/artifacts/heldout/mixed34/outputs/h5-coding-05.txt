The original query is vulnerable to **Insecure Direct Object Reference (IDOR)** or **Broken Access Control**. By filtering only on `id`, any authenticated user can retrieve data from any other tenant if they guess or know a job ID belonging to a different tenant.

### Corrected Predicate

The `WHERE` clause must include **both** the `id` and the `tenant_id` to ensure row-level isolation:

```sql
SELECT * FROM jobs WHERE id = $1 AND tenant_id = $2
```

> **Note:** `$1` is the job ID, and `$2` is the tenant ID (passed separately by the caller, as described in your prompt).
